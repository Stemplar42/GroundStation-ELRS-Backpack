# 06 - Pantallas del sistema

## Pantalla de arranque

El firmware muestra una pantalla de sistema con el título `GROUND STATION`, estado `BOOTING...` y descripción `ESP32 + TFT + BACKPACK`.

## Pantalla GENERAL

Muestra modo de vuelo, tensión de batería, porcentaje de batería, LQ, SNR y satélites.

## Pantalla HORIZONTE

Muestra horizonte artificial, pitch, roll, altitud GPS, velocidad, heading, tensión de batería, flecha HOME, distancia a HOME y mini brújula.

## Pantalla ENERGIA

Muestra tensión total, detección automática de celdas, tensión por celda, corriente, consumo mAh, porcentaje INAV y potencia RF interpretada.

## Pantalla GPS

En modo normal muestra coordenadas, satélites, altitud, velocidad, heading y datos HOME.

En modo RECOVERY muestra última posición GPS válida, altitud, Plus Code y QR a Google Maps.

## Pantalla DEBUG

Muestra contadores UDP, MSPv2, CRSF, tramas AIR, paquetes desconocidos, edad de datos UDP/TEL, LQ, estado HOME, estado GPS, RF e IP local.
