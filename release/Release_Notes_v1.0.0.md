# Release v1.0.0 Stable

## GroundStation V2.5.1 Professional Stable Release

Primera publicación estable del proyecto GroundStation ELRS Backpack.

## Incluye

- Firmware Arduino IDE completo.
- Configuración TFT_eSPI adaptada a ST7789 172 x 320.
- Documentación de hardware.
- Pinout.
- Manual de usuario.
- Sistema de alimentación recomendado.
- Solución de problemas.
- Logo SVG del proyecto.

## Funciones destacadas

- Telemetría ELRS Backpack por WiFi/UDP.
- Parser MSPv2/CRSF.
- Horizonte artificial.
- HOME automático.
- GPS RECOVERY con QR.
- Control de brillo PWM.
- Botón RESET físico.
- Alimentación autónoma con 18650.


## Gabinete 3D incluido en la documentación

La release queda preparada para incluir los STL finales del gabinete:

- `GroundStation_Case_Body_v18_SMOOTH_NO_REAR_LIP.stl`
- `GroundStation_Case_RearCover_v18_SMOOTH_NO_REAR_LIP.stl`

Estos archivos corresponden al **Case V18 SMOOTH_NO_REAR_LIP**. Si los STL no están dentro del ZIP, copiarlos manualmente a la carpeta `stl/` antes de publicar en GitHub.
