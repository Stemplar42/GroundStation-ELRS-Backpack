# STL files - GroundStation Case V18

The final case design for Release v1.0.0 uses the following STL files:

- `GroundStation_Case_Body_v18_SMOOTH_NO_REAR_LIP.stl`
- `GroundStation_Case_RearCover_v18_SMOOTH_NO_REAR_LIP.stl`

These STL files are not embedded in this documentation package because the chat platform did not allow uploading `.stl` or `.zip` files in the source conversation.

Before publishing the GitHub release, manually copy the two final STL files into this `stl/` folder using the exact filenames above.

## Case version

- Case version: V18
- Design variant: SMOOTH_NO_REAR_LIP
- Product release: GroundStation ELRS Backpack v1.0.0 Stable
- Firmware reference: GroundStation V2.5.1 Professional Stable Release

## Intended internal components

- ESP32 NodeMCU 38 pins USB-C
- TFT ST7789 1.9 inch display
- 18650 battery holder
- TP4056 charger module
- Step Down regulator adjusted to 3.30 V
- Main power switch
- NEXT and PREV buttons
- Physical RESET button between EN and GND
